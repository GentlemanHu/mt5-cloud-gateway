MetaTrader 5 云网关开发者文档

提供完整 REST API、双向行情流推送（Server-Sent Events 与 RFC 6455 WebSocket）、以及标准模型上下文协议 (Model Context Protocol, MCP) 支持。所有接口具备毫秒级响应速度与严格并发超时隔离保护。

🤖 需要给其他 AI Agent / LLM 阅读？
本系统已生成专门针对大模型优化的纯文本文档规范，直接将 URL 发给 LLM 即可一键理解全量工具与参数。
🔐 接口鉴权规范 (Authentication)

除公开文档页面 (`/docs`, `/llms.txt`, `/openapi.json`) 外，所有数据和交易接口均需认证。在管理面板生成专属 Bearer 令牌（格式 mt5_live_...），支持三类传入方式： 

# 方式 1: HTTP Header (推荐)
Authorization: Bearer mt5_live_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx

# 方式 2: X-API-Key Header
X-API-Key: mt5_live_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx

# 方式 3: URL Query 参数
GET /status?token=mt5_live_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx

GET /tick

获取指定品种的最新实时 Tick 盘口，支持智能自动匹配大小写和 m 后缀（如输入 xauusd 自动匹配交易商的 XAUUSDm）。

参数名类型必填说明

响应 JSON (200 OK)
{

  "symbol": "XAUUSDm",
  "data": {

    "time": "2026-10-09 00:05:12",
    "timestamp": 1791475512,
    "bid": 4122.50,

    "last": 0.0,
    "volume": 0.0
  }
}
GET /rates & /kline

高精度多维 K 线(OHLCV)检索引擎：支持全量周期 (M1 至 MN1 及别名)、任意长度检索 (支持 10,000+ 柱)、时间范围检索、偏移分页，并实时标记当前正在波动的未收盘柱 (is_closed: false)。

参数名类型默认值说明
symbolstringXAUUSD品种代码，支持模糊后缀解析（如 XAUUSD -> XAUUSDm）
timeframestringM1周期：M1, M2, M3, M4, M5, M6, M10, M12, M15, M20, M30, H1, H2, H3, H4, H6, H8, H12, D1, W1, MN1（亦支持 1m, 5m, 1h, 1d 等）
count / limitint500获取 K 线数量（支持 10 至 50,000+ 柱的大批量请求）
start / offsetint0起始柱偏移位置（0 为最新柱，向前历史回溯）
start_time / fromstring-起始时间（支持 ISO 8601 如 2026-10-01T00:00:00 或 UNIX 时间戳）
end_time / tostring-结束时间（与 start_time 配合进行确定时间段切片）
include_formingbooltrue是否包含当前正在波动的未收盘实时柱 (is_closed: false)
请求示例 1: 基础周期查询 (含当前实时形成中柱)
curl -s -H "Authorization: Bearer <TOKEN>" "http://localhost:18812/rates?symbol=XAUUSD&timeframe=M1&count=2"
请求示例 2: 大批量分页查询 (拉取 5,000 根 H1 K 线)
curl -s -H "Authorization: Bearer <TOKEN>" "http://localhost:18812/rates?symbol=XAUUSD&timeframe=H1&count=5000&start=0"
请求示例 3: 确定时间范围历史切片
curl -s -H "Authorization: Bearer <TOKEN>" "http://localhost:18812/rates?symbol=XAUUSD&timeframe=D1&start_time=2026-01-01&end_time=2026-10-09"

SSE /rates/stream (动态 K 线推流)

基于 Server-Sent Events (SSE) 的长连接动态 K 线推送协议。自动维护当前周期的 forming candle，毫秒级推送柱内价格跳动、柱收盘 (kline_closed) 与新柱开盘 (kline_open)。

参数名类型默认值说明
symbolstringXAUUSD需要订阅的交易品种代码
timeframestringM1K 线周期 (M1-MN1)
tokenstring-认证 Bearer Token（可通过 URL 查询参数传递）
订阅命令示例
curl -N "http://localhost:18812/rates/stream?symbol=XAUUSD&timeframe=M1&token=<TOKEN>"
事件类型与数据格式
// 1. 连接就绪
event: ready
data: {"status": "connected", "symbol": "XAUUSDm", "timeframe": "M1", "timeframe_seconds": 60, "initial_rates": [...]}

// 2. 实时跳动更新 (形成中 K 线 OHLCV 刷新)
event: kline_update
data: {"time": "2026-10-09 19:47:00", "timestamp": 1791546420, "open": 4181.325, "high": 4183.747, "low": 4180.484, "close": 4183.50, "tick_volume": 174, "is_closed": false, ...}

// 3. 周期时间走完，确认收盘
event: kline_closed
data: {"time": "2026-10-09 19:47:00", "timestamp": 1791546420, "open": 4181.325, "high": 4183.747, "low": 4180.484, "close": 4183.211, "is_closed": true, ...}

// 4. 新周期开启，新 K 线初始化
event: kline_open
data: {"time": "2026-10-09 19:48:00", "timestamp": 1791546480, "open": 4183.211, "high": 4183.211, "low": 4183.211, "close": 4183.211, "is_closed": false, ...}
POST /order

向 MetaTrader 5 发送市价交易订单。

请求体 JSON (Request Body)
{
  "symbol": "XAUUSDm",
  "action": "buy",
  "volume": 0.01,
  "price": 4122.50,
  "sl": 4110.0,
  "tp": 4140.0,
  "comment": "AI Bot Order"
}
请求示例
curl -s -X POST "http://localhost:18812/order" \
  -H "Authorization: Bearer <TOKEN>" \
  -H "Content-Type: application/json" \
  -d '{"symbol":"XAUUSDm","action":"buy","volume":0.01,"sl":4110.0,"tp":4140.0}'
响应 JSON (200 OK)
{
  "status": "ok",
  "order": 12849120,
  "deal": 12849120,
  "price": 4122.74,
  "volume": 0.01
}

MCP 模型上下文协议 (Model Context Protocol)

网关原生实现了 Anthropic/Model Context Protocol (MCP) 标准，支持 Streamable HTTP、SSE 与 Stdio 三种传输方式，暴露出 13 项交易与系统运维工具：

工具名称功能描述核心输入参数
mt5_get_status获取终端连接状态与版本无
mt5_get_account获取账户资产余额与净值无
mt5_get_tick获取最新实时盘口价格symbol
mt5_get_rates拉取全周期历史与动态K线序列(含形成中柱)symbol, timeframe, count, start, start_time, end_time, include_forming
mt5_list_symbols查询支持的品种列表group (可选)
mt5_get_symbol_info查询品种规格与参数symbol
mt5_get_positions获取未平仓持仓列表无
mt5_get_orders获取挂单列表无
mt5_order_send提交交易订单 (买/卖)symbol, action, volume
mt5_position_close平仓持仓单ticket
mt5_restart_terminal安全重启 MT5 终端无
mt5_restart_gateway重启网关服务无
mt5_get_logs获取最新运行日志lines
MCP Streamable HTTP 调用示例 (tools/call: mt5_get_rates 任意周期大批量检索)
curl -s -X POST "http://localhost:18812/mcp" \
  -H "Authorization: Bearer <TOKEN>" \
  -H "Content-Type: application/json" \
  -d '{
    "jsonrpc": "2.0",
    "id": 1,
    "method": "tools/call",
    "params": {
      "name": "mt5_get_rates",
      "arguments": {
        "symbol": "XAUUSDm",
        "timeframe": "M15",
        "count": 1000,
        "include_forming": true
      }
    }
  }'
GET /mcp/client.py (便携式 Stdio 桥接客户端)

专为 Cursor、Windsurf、Claude Code、Tabby 及终端环境提供的跨平台便携 Stdio-to-HTTP 桥接脚本。零第三方依赖（仅使用标准库 urllib），零机器本地路径硬编码与泄漏，面向外部任意环境通用。

方式 1: 直接下载便携客户端并在本地执行
# 1. 从网关下载标准客户端
curl -fsSL http://localhost:18812/mcp/client.py -o mt5_client.py

# 2. 传入 Token 启动 Stdio 桥接器
python3 mt5_client.py --token "<YOUR_TOKEN>"
方式 2: Claude Desktop 原生直连配置 (推荐，零本地 Python 依赖)
// ~/Library/Application Support/Claude/claude_desktop_config.json
{
  "mcpServers": {
    "mt5-gateway": {
      "url": "http://localhost:18812/mcp/sse?token=<YOUR_TOKEN>"
    }
  }
}
方式 3: 零文件单行免下载管道启动
MT5_GATEWAY_TOKEN="<YOUR_TOKEN>" python3 -c "import urllib.request; exec(urllib.request.urlopen('http://localhost:18812/mcp/client.py').read().decode('utf-8'))"
